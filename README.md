# Praneel Mohan — portfolio (v4)

Static, buildless site: social media & performance marketing portfolio.

- `index.html` home · `work.html` all work with filters · `performance.html` 850-lead case study · `uth-times.html` U'th Times case study · `about.html` experience and skills
- `css/pm.css`, `js/pm.js` shared styles and interactions (video lightbox, filters, count-ups, chart animation)
- `build.py` regenerates the five pages: `python3 build.py`

Media (`assets/`: videos, posters, thumbnails, creatives, CV) is kept off GitHub on purpose and deployed only to Netlify.
